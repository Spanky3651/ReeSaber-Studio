Quick Start — how to build a ReeSaber preset in 4 steps
1
Pick a starter

Use New ▾ → template for a ready-made saber, or start blank. Each preset is one saber config file.

2
Stack modules

Add a Blade, then layer Trails, Sparks and effects. Order = render order. Toggle the dot to mute a layer.

3
Tune & drive

Open the accordions to shape mesh, material and color. Add Drivers to make a layer react to Score, Velocity, cuts & more.

4
Check & export

Watch the Live JSON and Validate tabs on the right. When it's green, hit Export and drop the file into ReeSabers.
